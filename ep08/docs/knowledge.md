## K01 动词的五种形式
| 名称 | eat | run | make |
|---|---|---|---|
| 原形 | eat | run | make |
| 第三人称单数 | eats | runs | makes |
| -ing 形式 | eating | running | making |
| 过去式 | ate | ran | made |
| 过去分词 | eaten | run | made |
今天重点用第三行；第四行在第 9 集深入，第五行在第 14、15 集深入。同一个词形可承担不同作用，不能只见 -ed 就认定过去分词。

## K02 现在进行时：正在做
主语 + am/is/are + doing。I am reporting.（我正在报道。）Mia is drawing.（Mia 正在画画。）They are following Biscuit.（它们正跟着 Biscuit。）I 配 am，单数 he/she/it 配 is，you/we/they 配 are。

## K03 -ing 怎么拼
| 规则 | 例子 | 提醒 |
|---|---|---|
| 通常直接加 ing | study→studying；see→seeing；think→thinking | y 不变，ee 不去 |
| 不发音 e 去掉再加 ing | make→making；hide→hiding | 不是所有结尾 e 都去 |
| 重读末音节，短元音后一个辅音字母常双写 | run→running；sit→sitting；begin→beginning | w/x/y 不双写：fix→fixing |
| 少数 ie 结尾改 y | lie→lying；tie→tying；die→dying | lying 这里是“躺着” |
| 少数 c 结尾补 k | picnic→picnicking | 不把它套给所有 c 结尾词 |

## K04 否定和提问
否定在 be 后加 not：Biscuit is not sitting. = Biscuit isn't sitting.（Biscuit 没坐着。）疑问把 be 提前：Is Biscuit running?（Biscuit 正在跑吗？）Yes, he is. / No, he isn't. 不说 does running。问做什么：What are they doing?（他们正在做什么？）

## K05 眼前、现阶段与平时
进行时可说眼前动作，也可说这段时间的活动：Mia is learning about dinosaurs this week.（Mia 这周在研究恐龙。）她此刻可能休息。一般现在时说习惯：Sam usually plays football.（Sam 平时踢足球。）对比 Sam is hiding now.（Sam 现在正躲着。）now/Look 是线索，不是机械公式。

## K06 直接说指令
动词原形开头：Stop, Biscuit!（停下，Biscuit！）Put the egg down gently.（把蛋轻轻放下。）Be quiet.（保持安静。）否定：Don't run. / Don't be noisy.（不要跑／别吵。）Never touch the eggs.（绝不要碰蛋。）please 可放句首或句末：Please wait. / Wait, please. 通常省略的主语是 you。

## K07 提议和简短禁令
Let's go together.（我们一起走吧。）Let's 通常把说话人和听话人都包括进去。Let us go, please. 在请求对方放行时意思是“请让我们走”。No + doing：No shouting!（禁止喧哗。）No + 名词：No photos!（禁止拍照。）This way, please!（请走这边。）是常见简短指令。

## K08 有些意思通常不用进行时
know/like/want/belong 表示相应状态时通常用一般现在时：Lily knows the way now.（Lily 现在知道路了。）同一个动词可换意思：I think the egg is safe.（我认为蛋很安全。）I am thinking about a plan.（我正在考虑一个计划。）不能把所有 think/look/have 一律禁用进行时。

## K09 先留一个预告
现在进行时还能表示已安排好的将来活动，如 We are leaving tomorrow.（我们明天离开。）第 10 集再比较它和 will、be going to。
