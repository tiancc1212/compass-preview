# 第2集插图来源

19张正式图均由 Codex 内置 image_gen 制作，不使用外部图片素材、API付费路径或其他生成服务；本次没有为生图配置 API Key，也没有触发额外购买或订阅。现有角色设定由家长提供，用于保持同一组原创动画人物。三张私有参考和本集船长设定只存本地，没有复制到公开工程。

船长为本集新增原创配角：壮实中年、暖棕胡须、深蓝上衣、棕色皮背心、灰色无角月牙头盔。先制作参考，再用于清单和旧棋盘场景。固定角色每次都附原始主设定，避免逐张参考产生漂移。

正式图片内容修改只用内置 image_gen。Pillow 只用于尺寸调整、微量比例裁切、JPEG压缩与本地检视拼图。正式JPG不含提示词、字幕、编号或水印；字幕和棋盘线索由网页叠加。

完整实际提示词见 [PROMPTS.md](PROMPTS.md) 和 [PICTURE_CHOICE_PROMPTS.md](PICTURE_CHOICE_PROMPTS.md)，逐图尺寸及核验见 [ART_CHECK.md](ART_CHECK.md)。原始PNG和调用日志已另存英语项目的第2集插图本地资料目录，不作为网页资源。
