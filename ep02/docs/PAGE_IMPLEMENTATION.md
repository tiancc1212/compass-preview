## 奖励自然结束后的重播窄修复

复核又发现一条此前没有覆盖的路径：奖励自然 ended 后，原播放器重播创建独立 Audio；此时下一步已解锁，立即切题会让上一句继续播放。使用当前真实第 2 集音频、完全不拦截请求／不注入时钟的 `/tmp/ep02_replay_after_end.mjs` 已先复现失败：`renderedStep=2` 且 `replayedAudioStillPlaying=true`。

采取最小修复：题卡存续时，重播按钮的捕获阶段先停止当前奖励／上一段重播，保证不会积累多个播放实例；切下一题或关闭最后题卡之前，再停止当前播放器和 Audio。此处选择**切题时取消重播**，下一步可以立即显示，但新题不能带着上一题的音频播放。题卡结束时移除捕获监听，不改共享播放器块。

同一窄测试已转绿：自然 ended → 重播 → 立即下一步，结果为 `renderedStep=2`、`replayedAudioStillPlaying=false`。额外验证最后一题自然 ended → 重播 → 自动关卡：题卡关闭，全部奖励／重播实例均 paused 或 ended，没有音频溢入下一段。原播放器块字节一致、脚本语法检查通过。
