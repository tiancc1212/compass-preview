# 第 7 集 巧克力星球 · 练习题计划

无听力题。所有练习音频仅在答对或整题完成后播放，只录正确句；答错先给中文解释，不提前播放答案。每题独立作答，不显示分数或通关门槛。徽章沿用黄铜罗盘风格；动画仅作短暂答题反馈。

输入题忽略首尾空格、英文大小写及句末标点；只接受本题列出的答案和接受集，不放宽关键语法。分类盒及连线目标可重复使用，卡片和目标顺序独立打乱；表中的答案是映射而非屏幕顺序。

## 出题与制作边界

Q3 的小图只用于可见数量、大小、颜色或闭眼睡姿；不让孩子凭画面猜味觉。Q4 的味道由题干英文给出。Q6 只练标准感叹语序，不把带特殊口语语气的倒装一概判为全语言错误。

题量：8 组，36 道独立小题；Q8 为 8 道判断。看图题题干中给足语境，不依赖图片中的文字、时间暗示或不可见心理。错句只出现在改错/判断或明确标注的错误选项，不进入录音。
