## 教辅勘误

| 原文（本地教辅） | 问题 | 正确说法与本集处理 |
|---|---|---|
| 过去完成时“侧重过去的动作对现在造成的影响” | 把参照点写成现在 | 参照过去时点；采用K01–K03。[British Council](https://learnenglish.britishcouncil.org/free-resources/grammar/english-grammar-reference/past-perfect) |
| “发生在前，用过去完成时” | 过度绝对 | 是否要显出更早层次取决于语境；先后已明确时一般过去时也可，不出多解判错题。 |
| We were gave the book by him.；He->him“宾格变主格” | 分词、格的方向错 | given；he主格转him宾格。采用Q7.1。 |
| This watch is made in Swiss. | 国名错 | in Switzerland；Swiss是国籍形容词等。 |
| More trees must by planted ever year. | by/be、ever/every拼写错 | must be planted every year。 |
| Many houses was washed away… | 主谓不一致 | houses were washed away。 |
| Chinese…in world. | 缺the | in the world。 |
| He said he would made…；He can by found… | 原形与be错 | would make；can be found。 |
| “let、make、have…to必须还原” | 将make等规则泛化 | make常为be made to；let常换be allowed to；have sb do不机械被动。 |
| The children should by taken…；is operated on him；have send for | 助动词及分词错 | should be taken；主动is operating on him；have sent for。 |
| 不及物名单把close整体列入 | close也能及物 | The guard closed the door. → The door was closed. 看具体用法。 |
| “状态的及物动词不能使用被动” | 过度概括 | love/know等可以，如The crown is loved by everyone. |
| Watching TV is enjoyed…列作绝对错误 | 不自然不等于语法不成立 | 动名词短语可作主语；不把少用、累赘等同语法错误。本集不训练这种转换。 |
| This film is worthy being seen. | 缺of | worthy of being seen；本集只用worth visiting。 |
| look/sound等“本身已含被动含义” | 混淆状态描述与被动 | 系动词+形容词描述状态，不含统一的被动意义。 |
| The window was broken.一律判状态 | 缺上下文不能唯一判 | 加by the mouse说明动作，加still说明状态倾向。 |
| “系表结构通常只有一般现在和一般过去” | 限制错误 | will be empty、has been empty均可。 |
| “将来进行无被动”等口诀 | 将少见说成不可能 | 本集不展开复杂被动，不下绝对结论。 |

通用被动构成核对：[Cambridge Passive: forms](https://dictionary.cambridge.org/us/grammar/british-grammar/passive-forms)。其余拼写及一致性勘误直接对照本地原句，不改教辅原文件。
