# 第15集知识地图 · 伦敦博物馆失窃案

## K01 从过去回望更早
过去完成时用 **had + 过去分词**。先有一个过去参照点，再说明此前已经发生或持续到该时点的事。When we arrived, the crown had disappeared.（我们到达时，皇冠已经不见了。）不是“年代很久远”就用它，也不是任何两个过去动作都必须配过去完成时；先后已清楚时，一般过去时也可能自然。

## K02 过去完成时的句式
肯定：Lily had seen the crown. 否定：Lily had not seen the crown. / Lily hadn't seen the crown. 一般疑问：Had Lily seen the crown? 回答：Yes, she had. / No, she hadn't. 特殊疑问：What had Lily seen? 不管人称，助动词都是 had。

## K03 过去参照点与转述
By eight o'clock, the mouse had hidden the crown.（到八点时已经藏好。）The guard said he had locked the door.（转述时，锁门早于“说”。）时间先后由语境决定，不能只看一个关键词。过去完成时也能描述持续：The guard had worked there for ten years when we met him.

## K04 把承受者放在前面
Lily found the crown. → The crown was found by Lily. 被动的核心是 **be + 过去分词**；be及前面的助动词体现时态和主语单复数。by说明执行者；不知道或不必强调时可省略。不是中文出现“被”才可以用被动。

## K05 被动的否定与疑问
The crown was not found. / The crown wasn't found. Was the crown found? Yes, it was. / No, it wasn't. Where was the crown found? 有多个助动词时，否定放在第一个后面，疑问把第一个提前：Has the crown been found? 主语本身为疑问词时不额外倒装：What was stolen?

## K06 常用被动形式
| 所表达的时间或意思 | 形式 | 例句 |
|---|---|---|
| 平时 | am/is/are + done | The crown is kept in a case. |
| 过去 | was/were + done | The crown was stolen. |
| 将来 | will be + done | The crown will be returned. |
| 已经，关联现在 | have/has been + done | The glass has been broken. |
| 能、应该、必须 | can/should/must be + done | The glass can be repaired. |
| 正在被做 | am/is/are being + done | The crown is being cleaned. |
| 过去正在被做（认识即可） | was/were being + done | The case was being cleaned when we arrived. |
| 过去之前已被做 | had been + done | The crown had been hidden before we arrived. |
| 从过去看将来（认识即可） | would be + done | Lily said the crown would be returned. |
| 已有安排（认识即可） | am/is/are going to be + done | The case is going to be repaired. |

## K07 转换时保留信息
He gave us a torch. → We were given a torch by him. 宾格us变主格we，主格he在by后变him。双宾语还可变：A torch was given to us by him. buy则用for：A new torch was bought for us. 不把given写成gave。

## K08 不丢词，不乱补to
Lily looked after the mouse. → The mouse was looked after by Lily. 词组里的after保留。The guard made Leo wait. → Leo was made to wait. see/hear sb do改被动常恢复to；see sb doing改被动仍保留doing：The mouse was seen running away. 不把这一规则机械套到let、have；let常换be allowed to，have sb do通常换说法。

## K09 不能见动词就改被动
The crown disappeared. / The accident happened. 这里没有宾语，不能加be硬改被动。The crown belongs to the museum. 也不改成“is belonged to”。拥有have、常见反身/相互结构不做机械转换。但“所有状态动词都不能被动”不对：The crown is loved by everyone. 是正常句子。

## K10 动作与状态要看语境
The case was broken by the mouse. 描述被弄坏的动作。The case was still broken. 描述仍然坏着的状态。不能只看was broken就给所有句子下同一种结论。系表结构也能用于其他时态：The case will be empty tomorrow.

## K11 用主动形式表达
The guidebook sells well.（这本导览册畅销，说明特点。）The case needs cleaning. = The case needs to be cleaned. The museum is worth visiting. 系动词look/smell等接形容词是在描述状态，不统称为“含被动意义”：The crown looks beautiful.

## K12 两条线分别看
had disappeared = 过去完成、主动；was hidden = 一般过去、被动；had been hidden = 过去完成、被动。先看“什么时候”，再看“谁做／谁承受”。本集只建立形式和意思的对应，不要求一次背熟所有被动时态。
