## 教辅勘误

| 原文/说法 | 问题 | 正确说法与采用方式 |
|---|---|---|
| So dose Tony. | 拼写错 | So does Tony.；本集Q1匹配助动词。 |
| Mary didn't watched TV… | did后未还原 | didn't watch；不把错句录音。 |
| “方位副词开头…要用倒装” | 适用范围过宽 | 呈现人物/动作的here comes等常倒装，非任意地点句强制。 |
| “如果主语是代词，则不能用倒装” | 离开here类语境会误导 | 限定为此种完全倒装；So do I恰有人称代词却需部分倒装。 |
| “句首有not only…部分倒装” | 省略条件 | not only修饰主语时不因此倒装；only同样要看作用位置。 |
| “两种或以上的修饰”用so it is with | 术语不准确 | 是不同谓语情况的综合呼应，不是数修饰语；本集不展开。 |
| “whose=of which” | 易误作原位替换 | whose cover / the cover of which等需连同名词位置调整。 |
| “数词、形容词…只能that” | 过度概括 | 普通数词或形容词不排除which；本集接受合法that/which。 |
| “只能who不能that”长表 | 多处把偏好写成绝对规则 | 限定性从句中who/that常都可用；非限定性才有明确的that禁用边界。 |
| What it is that we want? | 问句词序错；例子分类混乱 | What is it that we want? 是强调式疑问，不拿来演示what作先行词。 |
| He is not the man that he used to be.译“他以前不是这样的人” | 时态焦点倒置 | 他已经不是过去的他了。 |
| Anyone，who does that… | 不应逗号切断必要说明 | Anyone who does that…；本集用短限定句。 |
| People that have not properly trained… | 漏被动been | People that have not been properly trained… |
| “完全取决于从句中的谓语动词” | 只看动词忽视空缺成分 | 应还原先行词，看从句缺主语、宾语还是状语。 |
| 非限定“不能用who代whom” | 过于绝对 | 非限定中who也可作宾语；前置介词后用whom。 |
| 定从表把when列在指人一行 | 表格分类会误导 | when对应时间先行词且作状语，不表示人。 |
| It was the first time that he had cooked meal for my parents. | meal缺限定；中文主语错 | he had cooked a meal；中文应为“他第一次…”。本集不采用。 |
| been to American | 国名错误 | been to America。 |
| as might be excepted | 词拼错 | as might be expected。 |
