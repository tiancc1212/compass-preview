# 第 1 集剪映音色选择

本集采用与本轮其他 8 集一致的固定角色映射：旁白「英伦学姐（English）」、Leo「Energetic Male(English)」、Sam「Gentle Guy（English）」、Lily「Gentle Girl（English）」。无新增角色音色。

四个角色分别在独立剪映草稿中从真实音色卡片选择，核对青色选中边框、名称与英语标签。旁白 3 条补录沿用同一草稿相同音色。每个批次均确认生成实际音轨及导出成功；每句最终来源可回溯，详见 VOICE_CONSISTENCY.md。

按用户最新要求，本轮只验实际选音和固定制作流程，不做听感、口音、清晰度或年龄感验收，也不声称听过。剪映选音界面记录及截图保留在本地 shots/voice_consistency，不上传公开仓库。
