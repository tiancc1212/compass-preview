## 明确的验证边界

- storage/pageshow 是**单页事件处理器测试**，不会伪称原生跨标签 storage 或实际浏览器 bfcache 已验收。此界限同时写入输出 JSON。
- reduced-motion 测试覆盖真实媒体查询与样式/运行模式，不另走完整单集结尾，未在该脚本宣称飞星结束路径已验收。
- source metadata 和审定文案取本地 `hq/hq.js`；解锁状态使用独立明确的业务 fixture，不直接重写产品的解锁公式作为唯一判据。
- 所有按钮 activation 都经过 `elementFromPoint` 与 `mouse.click`。原生语速控件先真实点击验证可达，最终脚本用标准表单 `select` API 选值并核验状态及持久化；没有调用 `__auto`、`__go` 或总部隐藏操作函数。

## 问题归因与修正

- 真实产品问题：首次访问默认 `/favicon.ico` 返回 404，主代理已添加共享 SVG favicon；所选有效七尺寸均为修正后结果，无 404。
- 测试入口：单集首页设计上隐藏 HUD 按钮，实际总部入口在首页操作区；测试改为选取当前可见的两个真实入口，仍严格要求整控件入屏及鼠标命中。
- 测试下载节奏：极快连续点击 11 次下载时，第 11 次未落盘；各次增加 350ms 正常操作间隔后，11 份均完成真实下载。未绕过浏览器下载保护，未削弱落盘或 HTTP 断言。
- 测试列表滚动：`scrollIntoView(center)` 受 scroll-padding 影响，把矮横屏人物卡底部留在视口外；普通列表允许正常滚动，测试补充滚至 block:end 后仍严格检查整卡入屏及命中。序章主控继续禁止滚动补救。
- 测试原生菜单：macOS 桌面原生 select 弹出菜单不接受本次 CDP 键盘选择。按主代理明确边界，改用真实鼠标点击控件加标准表单选择，并完整验证实际 rate 和持久化。未使用应用内部函数。
