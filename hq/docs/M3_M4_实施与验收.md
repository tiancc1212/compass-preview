### 性能与动效证据

同一 Chrome、本地未压缩 HTTP、冷缓存、Fast 4G（延迟 170ms、下行 1.6Mbps、上行 750Kbps）的单次对比：

| 指标 | v4 | v5 发布候选 |
| --- | ---: | ---: |
| 引擎就绪 | 10,073 ms | 3,192 ms |
| 新版字体与图片齐备 | — | 3,221 ms |
| 首屏子资源实际传输 | 1,646,195 B | 233,073 B |

首屏传输口径来自浏览器 resource entries，不含顶层导航 HTML。单集共享引擎 JS/CSS、全部罗盘档位及字体的 gzip 合计 283,256 B，低于 400 KB。实际传输减少 1,413,122 B；旧版 gzip 本身仅约 341 KB，不能声称“gzip 减少 1 MB”。单次节流测量不代表所有线上设备的速度。

自然飞行实测 1,209ms、光晕 600ms；鼠标和 Escape 跳过通过。真实 `prefers-reduced-motion: reduce` 下无飞行或光晕，星星仍保存；四种场景均没有 3D 请求、脚本或资源错误。见[原始结果](qa/本地动效与性能.json)。

已审定罗盘原图原生为 **1254×1254**，保留原图并发布 1024/512 两档；未放大冒充任务书最初的 2048 原生图。

完成页的长正文在卡片内滚动，底部“冒险队总部 / 再玩一次”保持可点；完整回归同时验证全部 77 个组合。见[本地完整通关日志](qa/本地单集七尺寸完整通关.log)。
