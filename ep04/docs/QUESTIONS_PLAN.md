# 第 4 集 · 题目计划

题目为亲手参与的活动，不计分、不排名。输入忽略大小写、首尾空格和句末标点；词形和内部语序必须正确。明确列出可接受答案，不能靠模糊关键词判对。每组题序可乱序，选择项分别乱序，不能按答案位置作答。徽章沿用黄铜罗盘 S/V/O/C/DO 等；不新增表情图标。动画只作短暂答题反馈。所有音频均在答对或订正完成后播放，绝不预播。

## Q1 挑对帮手 · 分类

### Q1.1 · 分类

- 题干：卡片 I / the dragon / you / Mia and Sam；放入 be 的 am / is / are 三盒。
- 答案 / 接受集：I→am；the dragon→is；you→are；Mia and Sam→are。
- 干扰项 / 常见错法：I→is；you→am。
- 答错解释：be 跟主语配对，you 即使只有一个人也用 are。
- 答对音频：`audio/ex_q1_1.mp3` — You are ready.

### Q1.2 · 分类

- 题干：卡片 We like books. / She likes books. / He liked books yesterday.；问句帮手三盒 do / does / did。
- 答案 / 接受集：We like→do；She likes→does；He liked yesterday→did。
- 干扰项 / 常见错法：过去句选 does。
- 答错解释：do 对现在的复数等主语，does 对现在三单，did 管过去；过去细讲在第9集。
- 答对音频：`audio/ex_q1_2.mp3` — Did he like books yesterday?

### Q1.3 · 分类

- 题干：按造问句时“直接提前”或“需要 do/does”分：is / can / likes / read（主语 they）。
- 答案 / 接受集：直接提前 is/can；需要帮手 likes/read。
- 干扰项 / 常见错法：can→需要 does。
- 答错解释：已有 be 或 can 就直接提前；普通实义动词请 do/does。
- 答对音频：`audio/ex_q1_3.mp3` — Can the dragon fly?

### Q1.4 · 连线

- 题干：左：do not / does not / is not / are not / cannot；右乱序：aren’t / can’t / doesn’t / don’t / isn’t。
- 答案 / 接受集：do not→don’t；does not→doesn’t；is not→isn’t；are not→aren’t；cannot→can’t。
- 干扰项 / 常见错法：把 is not 配成 don’t。
- 答错解释：缩写保留原来的帮手；cannot 通常写一个词。
- 答对音频：`audio/ex_q1_4.mp3` — The dragon cannot swim.

### Q2.3 · 改写

### Q2.5 · 连线

## Q5 问题地图 · 连线与填空

### Q5.1 · 连线

- 题干：问的信息：人 / 物品 / 地点 / 原因 / 时间 / 方法；词卡乱序 where / how / who / when / why / what。
- 答案 / 接受集：人→who；物品→what；地点→where；原因→why；时间→when；方法→how。
- 干扰项 / 常见错法：地点→when；原因→how。
- 答错解释：先想缺什么信息，再选疑问词。
- 答对音频：`audio/ex_q5_1.mp3` — Where does the dragon live?

### Q5.2 · 连线

- 题干：问题目标：年龄 / 距离 / 频率 / 时长 / 还要多久 / 可数数量 / 不可数数量或价钱；词卡乱序 how long / how many / how far / how much / how old / how soon / how often。
- 答案 / 接受集：年龄→how old；距离→how far；频率→how often；时长→how long；还要多久→how soon；可数→how many；不可数或价格→how much。
- 干扰项 / 常见错法：how often→时长；how soon→频率。
- 答错解释：often 问频率，long 问长度或时长，soon 问从现在到未来还多久。
- 答对音频：`audio/ex_q5_2.mp3` — How often does the dragon read?

### Q5.3 · 打字填空

- 题干：用 do / does / is：Where ___ the dragon live?
- 答案 / 接受集：does
- 干扰项 / 常见错法：do / is
- 答错解释：live 是实义动词，dragon 是三单，用 does。
- 答对音频：`audio/ex_q5_3.mp3` — Where does the dragon live?

### Q5.4 · 连词成句

- 题干：词块：riddles / Who / likes；问谁喜欢谜语。
- 答案 / 接受集：Who likes riddles?
- 干扰项 / 常见错法：Who does likes riddles?
- 答错解释：who 本身作主语，直接接 likes。
- 答对音频：`audio/ex_q5_4.mp3` — Who likes riddles?

### Q5.5 · 连线

- 题干：问句：What time is it? / What day is it? / What’s the date today? / What colour is the egg?；答句乱序：It is green. / It is Monday. / It is the fifth of May. / It is three o’clock.
- 答案 / 接受集：time→three o’clock；day→Monday；date→the fifth of May；colour→green。
- 干扰项 / 常见错法：day→日期；date→星期一。
- 答错解释：几点、星期几、几月几号是三种不同问题。
- 答对音频：`audio/ex_q5_5.mp3` — It is the fifth of May.

## Q6 两件事连起来 · 连线与填空

### Q6.1 · 连线

- 题干：关系卡：增加一件事 / 前后转折 / 提供选择 / 前因后果；词卡乱序 so / or / and / but。
- 答案 / 接受集：增加→and；转折→but；选择→or；结果→so。
- 干扰项 / 常见错法：原因→but；转折→and。
- 答错解释：连词要与两个分句的意义配套。
- 答对音频：`audio/ex_q6_1.mp3` — Mia asks a question, and Lily listens.

### Q6.2 · 打字填空

- 题干：只选 and / but / so：The dragon is huge, ___ he is friendly.（突出外表吓人却友好）
- 答案 / 接受集：but
- 干扰项 / 常见错法：and / so
- 答错解释：题干强调转折，所以用 but。
- 答对音频：`audio/ex_q6_2.mp3` — The dragon is huge, but he is friendly.

### Q6.3 · 打字填空

- 题干：只选 but / so / or：The cave is dark, ___ Leo uses a torch.（前面说明原因）
- 答案 / 接受集：so

- 答错解释：因为暗而用手电，是前因后果。
- 答对音频：`audio/ex_q6_3.mp3` — The cave is dark, so Leo uses a torch.

### Q6.4 · 改写

- 题干：把两句按“否则”连接：Ask clearly. The dragon cannot help. 使用 or。
- 答案 / 接受集：Ask clearly, or the dragon cannot help.
- 干扰项 / 常见错法：Ask clearly, and the dragon cannot help.
- 答错解释：or 也能表示否则，不只表示二选一。
- 答对音频：`audio/ex_q6_4.mp3` — Ask clearly, or the dragon cannot help.

## Q7 选哪个 · 问答与搭句子

### Q7.1 · 连词成句

### Q7.2 · 连线

- 题干：已知龙守书、不守金子。问句 Does he guard gold or books?；候选回答 A Yes, he does. B He guards books. C No, he doesn’t.

### Q7.3 · 改写

- 题干：用 and 连成一句：Mia likes riddles. Sam likes football.（保留两个分句）
- 答案 / 接受集：Mia likes riddles, and Sam likes football.；接受 Sam likes football, and Mia likes riddles.
- 干扰项 / 常见错法：Mia and Lily likes books.
- 答错解释：and 连接两个完整分句，各自保留主语和谓语，逗号放在 and 前。

### Q7.4 · 打字填空

- 题干：否定问句也按事实：Isn’t the dragon awake? 事实是龙醒着。填 Yes / No。

- 干扰项 / 常见错法：No, he is.
