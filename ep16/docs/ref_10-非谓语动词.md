## 动词不定式

非谓语动词

| 定义 | 在句子不做谓语成分的动词叫做非谓语动词，除了不能充当谓语之外，其他成分都可以承担。 |
| --- | --- |
| 形式 | ①动词不定式：to +V（to do） |
|  | ②动名词：V-ing（doing） |
|  | ③分词包括现在分词和过去分词： V-ing /V-ed（doing/done） |

### 1、动词不定式

| 形式 | ①肯定式（to do） |
| --- | --- |
|  | ②否定式（not to do） |
|  | ③疑问式（疑问词或疑问词组 + to do） |
| 说明 | ①动词不定式没有人称和数的变化，在句中不能作谓语； |
|  | ②一般来说，用不定式时，所表示的多为将来的行为； |
| 作主语 | ①单个动词不定式作主语的时候，谓语动词用单数； |
|  | To see is to believe. 眼见为实。 |
|  | ②如果 and 连接两个或更多并列的不定式作主语时，<br>被并列的不定式语义一致或基本一致时，谓语动词用单数；不一致时，谓语动词就用复数； |
|  | To love and to be loved is sweet to us. 爱或被爱对我们来说都是甜蜜的。<br>To improve people's lives and to speed up socialist construction are our two<br>important tasks today. 提高人民生活水平和加快社会主义建设是我们今天的两项重要任务。 |
|  | ③不定式做主语，常用 it 作形式主语，不定式后置，以避免头重脚轻的现象； |
|  | To learn a foreign language（做主语）is not easy. 学好一门语言并不容易。<br>=It(形式主语) is not easy to learn a foreign language（真正主语）. |
|  | How exciting it is to watch a wonderful football match tonight！<br>今晚能看到一场精彩的足球比赛是多么令人激动啊！ |
|  | ④常用结构： |
|  | 1）It +be + adj + of + sb. /sth. to do sth.；形容词如果是描述人的性格特征（如 kind、<br>good、nice、clever、foolish、silly）等时，一般用介词 of； |
|  | It's very kind of you to help me. 你帮助我真的太好了。<br>kind 修饰的是 you，可以理解为 you are kind to help me，表示主表关系，所以用 of； |
|  | 2）It +be + adj + for + sb. /sth. to do sth；形容词如果是修饰事物的（如 easy、hard、<br>difficult、important、necessary、impossible、thoughtful[考虑周到的、体贴的]）等时，<br>常用介词 for，for 后面的宾语可以看作是动词不定式的逻辑主语； |
|  | It's difficult for him to give up smoking. 对他来说戒烟是很困难的。<br>注：difficult 修饰 give up smoking 戒烟这件事，戒烟这件事是很困难的，故用 for。 |

|  | I think it important for us to study English well. 我认为学好英语对我们很重要。 |
| 作宾补 | 动词不定式做宾补常见动词见下页； |
|  | He asked me to go. 他叫我去。 |
| 作状语 | ①目的状语：放在 go，come，use，live，in order 等词后面； |
|  | I come here to meet you. 我来这去见你。<br>He runs fast in order to get there in time．他跑得很快为了及时赶到那里。<br>To learn English quickly and well, he went to England.<br>为了更快更好地学英语，他去了英国。 |
|  | ②原因状语：放在 sorry，glad，surprised，disappointed，excited 等词后面； |
|  | I am glad to see you here．我很高兴在这见到你。 |
|  | ③结果状语： |
|  | I went to the station only to find the train had gone.我去了车站，却发现火车已经开走了。 |
|  | ③用于固定结构中，如：too···to···(表否定)，enough···to，only to do，so/such···as to 等； |
|  | He is too young to go to school. 他太小了还不能上学。<br>=He is not old enough to go to school.<br>He has enough money (=money enough) to buy a car. 他有足够的钱买一辆汽车。<br>He worked day and night in order to/so as to succeed.他夜以继日地工作是为取得成功。 |

## 动名词

### 2、动名词

| 做宾语 | ①作动词宾语，常见动词见下； |  |  |  |  |  |

总结

| 列1 | 列2 |
| --- | --- |
| 1 | 不定式 to do 有还没有做的含义； |
| 2 | 动名词 doing 表示抽象的名词意义； |
| 3 | 现在分词 doing 表示主动或正在进行的意义； |
| 4 | 过去分词 done 表示被动或完成的意义。 |
