# 第 11 集 练习题计划

每题先独立作答，答对后才播放表中的正确句；改错题只录改正句。答错先显示中文解释，不能用音频提示答案。无听力题，不设通关门槛或成绩评级。黄铜罗盘徽章只作结构标签；动画仅用于答题反馈。

输入题忽略句首大小写、首尾空格及句末标点；不接受词形、时态或词序错误。缩写仅在题目接受项列出时等价。分类卡、连线两端分别打乱，不能用同位置匹配；表中顺序是审稿顺序。
